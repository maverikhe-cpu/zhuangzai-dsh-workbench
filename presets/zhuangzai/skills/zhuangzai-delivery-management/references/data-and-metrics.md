# 工地月报：数据与口径

以下是取数方向，不是固定参数表。每次根据当前 MCP 工具说明确定参数、权限范围、上限与返回字段，优先按任务相关模块查询。分页、失败和遗漏要有记录；不完整时不声称完整统计。

| 管理问题 | 优先工具 | 处理要点 |
|---|---|---|
| 当前有哪些工地、负责人和阶段 | `list_projects`，必要时 `get_project_detail`、`list_project_stage_progress` | 当期列表是当前快照，不自动等于历史月末在建；当前在建按 [公司管理口径](company-policy.md) 读取本公司已确认的排除规则，不默认沿用其他公司的阶段名单。计划和系统阶段、AI 识别阶段分别描述。 |
| 本月发生哪些问题、处理进展如何 | `list_issue_records`；单条核实 `get_issue_detail` | 按发生时间取数，六种状态分别统计；整改、审核、申诉区分。闭环定义、是否排除误判等先遵循客户确认的口径；没有统一口径时给状态分布。历史月末未闭环需有对应时点记录。 |
| 工地形象如何 | `list_tidiness_records` | 按采集记录统计优、良、差、未知；记录数不等于工地数。未知单列；需算工地覆盖时按工地 ID 去重并确认分母。 |
| 哪些现场被 AI 多次识别风险 | `list_detection_records`（按工具要求区分行为、物体） | 展示识别次数、类别及关联工地；一条记录可能有多个类型。无全部采集或有效检测分母时不计算违规率，也不把识别次数等同违规人数。 |
| 现场有人到过哪些工地 | `list_sign_in_records` | 多工地或多人员时按日期批量分页（当前上限每页 50），在本地按 projectId、signerId 和日期汇总，不逐工地或逐人请求；核对总数和缺页。keyword 仅模糊搜索，不能代替精确工地关联。签到不等于有效巡检或施工工时。 |
| 哪些工地进行了远程查看 | `list_patrol_records` | 一条记录为一次线上查看，不含时长；不传部门可能仅默认某个部门及下级。先核查返回的查询范围；某一明确范围内的巡检记录总数可直接使用 total，不必为记录总数逐页；涉及巡检人或工地去重、分布、多部门去重时才取完整明细。默认部门不一定是全公司。 |
| 摄像头本月在线情况 | `list_device_online_rate` | 用 `period` 查询月度时长口径；总体在线率按同范围在线秒数之和除应在线秒数之和，不直接平均百分比。日明细之和不一定等于周期结果，零分母不算在线率。 |
| 当前设备总数与闲置、领用、绑定、在线 | `list_device_inventory` | 当前权限范围设备台账；PC 页面在线/离线快捷统计要求 bound=true 与 online 组合，单独 online 包含未绑定设备。库存快照不冒充历史月末数据；ownerViewable 是工地级开关，未绑定缺失不算不可看。 |
| 月内现场变化 | `list_progress_updates`、`list_stage_detections` | 分清人工图文与 AI 阶段识别；关注识别时间。单工地查询须先选重点样本，不默认遍历所有工地。 |
| 其他客户关心的验收、派工、停工或工期 | 现有对应工具 | 按客户管理问题与实际字段补充，不将未启用或未记录的数据视为零。 |

**分类对账：** 已获得完整明细时优先程序分组并核对总数，不再重复逐分类查询。未取得明细而按分类筛选求分布时，先将各分类 total 与未筛选总数核对。可选分类未必覆盖所有记录；合计不足时单列未覆盖部分，或读取完整明细核实，不得把已有枚举当作全部分类。

**取数方法：** 查询按工具实际声明使用分页参数与时间字段；核对总数、翻页和截断状态。记录实际生效的公司、组织、时间、来源和单位。用于跨模块分析时优先按工地 ID 关联；无法可靠关联就分别呈现，不用相似名称强行拼接。公开报告中不包含无关的个人敏感信息，也不将客户数据写入技能文件或代码仓库。

**可参考的报告结构：** 月度概况 → 关键变化与优先事项 → 模块分析 → 需要跟进的工地／人员 → 可追问的明细。图示可以来自当前结果生成，不能复制样例客户的数字或结论。

**证据与表述：** 数量相同或同一工地同时出现两类记录，只能说明数量一致或同时出现，不能据此断言一一对应、自动生成或因果关系；需要可靠的逐条关联键或明确的产品规则。多日出现差评，应写明具体记录数和不同日期数，只有逐日证据连续才称连续；不能据此断言整个期间持续脏乱。未知评级不并入差评或违规；没有可比的采集总量时，不能单凭差评绝对数量上升断言现场变差。只有看到事实证据才陈述具体原因、阶段和整改情况，推测作为待核实线索。
