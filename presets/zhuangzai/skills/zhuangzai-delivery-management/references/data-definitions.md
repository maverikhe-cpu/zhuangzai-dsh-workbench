# 跨模块数据定义

参数和字段以当前宿主 schema 为准。这里保留共同原则，具体指标只维护在各场景文件中，避免重复口径漂移。

- **身份与范围**：projectId 用于关联工地；managerId 按工具定义关联人员。名称、地址、昵称相似不能替代稳定 ID。根部门不自动等于公司身份；不同工具默认部门与权限过滤可能不同。
- **日期**：当前状态、期间事件、历史时点快照分开。问题发生日不等于整改日，验收现场日期不等于提交/终审日，申请提交日不等于计划进场日，图文发布日期不等于拍摄日。
- **分页**：page 从 1 起，各工具上限不同。total 通常是筛选记录数，不是去重人数/工地数；施工动态 total 为已见条数下界，按短页结束。详见 [性能](performance.md)。
- **缺失**：零值、成功的空集合、可选字段省略、未知值、查询失败分别处理。只采用当前工具明示的缺键语义，不从一条记录推断公司配置。
- **公司口径**：完工/在建规则看 [公司口径](company-policy.md)。系统 status 与 currentStage 独立；list_projects 的过滤 in_progress 是全部在建，返回行 in_progress 是施工中，不同含义。
- **记录与人数**：签到不等于有效工时，巡检次数不等于时长，识别事件不等于违规人数，派工跨申请人数和不等于去重工人数。没有有效分母不算比例。
- **同源与关联**：数量相同不证明一一对应，时间接近不证明因果。关联失败时分别展示；需精确比较时固定公司、权限、筛选、时间、粒度。
