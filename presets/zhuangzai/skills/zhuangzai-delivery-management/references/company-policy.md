# 公司管理口径

完工、在建和负荷按公司规则计算，不内置客户名单，不从“最后一个阶段”猜终态。

## 采用哪条规则

1. 当前对话用户明确规则优先；否则复用同一公司已确认配置。仅本次分析的要求不自动覆盖长期配置。
2. 无约定时只确认关键项：“哪些情况算完工、不再计入负荷？只看手工标记，还是也包含某些阶段？”可先展示默认原始分布，业务排名等确认后给。不要让无关的设备/文件分析等待完工规则。
3. 工具返回 companyStages 时可作为阶段选项；列表已见阶段不保证完整模板。没有配置查询工具就让用户明确指定，不编造工具。

## 调用转换

`get_project_load_summary`：只看手工标记则省略 finalStages；标记 OR 阶段则传确认的精确名称列表，**不能传空数组**。响应 completionRule 核对本次实际规则，不在技能侧二次扣减。客户采用工具无法表达的规则时，用可靠完整明细计算或只交付可支持的范围。

## 保存与换公司

需要长期保存且宿主支持时，按已核实公司稳定 ID 隔离配置；记录公司、规则、终态名单、停工纳入方式、确认来源/日期与版本。根部门 ID 不能默认当公司 ID。配置中的空阶段名单可表达“仅手工标记”，调用时转换成省略参数。

写入前核对公司、保存后读回；不能确定公司 ID 时仅用于当前已确认会话。宿主不支持跨任务保留时不声称已长期记住，可输出配置文件由用户保存。切换公司重新载入该公司的规则；发现阶段改名或删除时核对映射，不自动改用末位阶段。客户配置不打进公开技能包。
